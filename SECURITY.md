# Security Policy

## Supported Versions

Security updates are currently provided for the latest stable release.

| Version | Supported          |
|---------|--------------------|
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in ChaosTree, please report it
privately rather than opening a public GitHub issue.

Please use GitHub's private vulnerability reporting feature:

**GitHub → Security → Advisories → Report a vulnerability**

When reporting a vulnerability, please include:

- A clear description of the vulnerability
- The affected version
- Steps to reproduce the issue
- A minimal example or proof of concept, if available
- Any potential impact you have identified

We will review the report and respond as soon as reasonably possible.

Please do not publicly disclose the vulnerability until it has been
investigated and, where appropriate, a fix or mitigation has been released.

## Security Updates

If a vulnerability is confirmed, a patched release will be published when
appropriate. Security-related changes will be documented in the release
notes.

Older unsupported versions may not receive security fixes. Users are
encouraged to upgrade to the latest stable release.
